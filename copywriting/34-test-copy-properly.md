# Rule 34: Test copy without fooling yourself

## What it is

Before trusting a copy change, check it with real buyers. Use message tests and surveys first. Run A/B tests only when you have the traffic for a fair result.

## Why it matters

Most famous copy "wins" are single tests with no sample size reported, run more than ten years ago, that changed several things at once. Running your own tests badly produces the same false confidence.

CXL's A/B testing rules:

- Fix the sample size before starting.
- Run whole weeks, across at least two business cycles.
- Avoid holidays and promotions.
- Never stop at the first sign of significance. CXL calls this the biggest beginner mistake.
- Be wary of fewer than 250 to 350 conversions per variation.

Most small business sites never reach those numbers. For them, qualitative testing is the realistic route.

## Testing without much traffic

- Message testing: Wynter runs B2B message tests with a panel it says numbers 86,000+ verified professionals, returning scores and quotes within 48 hours (vendor claims; paid).
- On-page surveys at checkout or pricing ("What's stopping you today?"), as Conversion Rate Experts used for Crazy Egg. Free.
- Five-second tests: show the hero for five seconds, ask what the company sells.
- Customer interviews: read the page aloud with a customer and note where they hesitate.

## Benchmarks (loose reference only)

Unbounce 2024: median landing-page conversion 6.6%, industry medians 3.8% to 12.3%. "Conversion" meant whatever goal each page set, so it isn't a target. Mobile brings nearly 5 times the visitors, but desktop converts 8% better, so read every page on a phone before it ships.

## Bad

Changing the headline on Monday, seeing more sign-ups by Wednesday, declaring a winner.

## Good

Five customer interviews reveal three unanswered objections. The page is rewritten to answer them. Then, with 600 conversions a month, an A/B test runs for four full weeks with the sample size set in advance.

## Fix

Start with qualitative research. Reserve A/B tests for pages with enough conversions. Change one main idea per test, and write down the hypothesis before you start.
