# Pattern 02: Corporate verb inflation

## What it is
Swapping a plain verb for a longer Latinate one that means the same thing.

## The swaps
| Inflated | Plain |
|---|---|
| utilize | use |
| leverage | use, or say what you actually did |
| facilitate | help |
| implement | build, add, do |
| optimize | speed up, cut, tune |
| initiate | start |
| terminate | end, stop |
| demonstrate | show |
| commence | begin |
| ascertain | find out, check |
| endeavour | try |
| regarding | about |
| prior to | before |
| in order to | to |
| a number of | some, or the actual number |

## Why it happens
Longer words read as more formal, and formality correlates with the "helpful assistant" register models are tuned toward.

## Threshold
More than once per 300 words where an inflated verb replaces a simple one.

## Bad
> We utilized the new API in order to facilitate faster data retrieval prior to the migration.

## Good
> We used the new API to speed up data reads before the migration.

## Fix
Read the sentence aloud. If you would not say the word to a colleague at a desk, cut it.
