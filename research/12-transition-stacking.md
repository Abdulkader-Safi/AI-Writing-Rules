# Pattern 12: Transition-word stacking

## What it is
Paragraphs that open with a formal connector, one after another.

## Watch words
Furthermore, Moreover, Additionally, In addition, Consequently, Nevertheless, Nonetheless, Ultimately, Notably, Importantly, That said, Indeed, Thus, Hence

## Why it happens
Connectors are how a model signals structure between chunks it generated separately. Human writers usually let the order of ideas do that work.

## Threshold
More than half of paragraphs opening with a formal connector.

## Bad
> Furthermore, the API supports batching.
> Moreover, rate limits are generous.
> Additionally, the docs are good.

## Good
> The API supports batching. Rate limits are 10,000 requests an hour, which we have never hit. The docs are good.

## Fix
Delete the connector and read the paragraph. If the link between ideas is now unclear, the problem is the order of the paragraphs, not the missing word.

Source: [SlopDetector](https://slopdetector.org/blog/signs-of-ai-writing)
