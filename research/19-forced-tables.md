# Pattern 19: Forced tables and forced structure

## What it is
Tabulating content that is not tabular. Bulleting content that is a paragraph. Numbering a sequence that has no order.

## Why it happens
Structure is how a model signals effort. A table looks like analysis even when the cells contain one word each, or when the second column just restates the first.

## The tells
- A two-column table where the second column is a synonym of the first
- A table with one row
- Bullets that are all full sentences and read in sequence, which means they were a paragraph
- Numbered steps that could be done in any order
- A table used because the content had exactly three items

## When a table is right
Three or more rows, two or more columns, and the reader wants to compare across a row or scan down a column. Comparisons, specs, mappings, schedules.

## Bad
| Benefit | Description |
|---|---|
| Fast | It is fast |

## Good
> It is fast.

## Fix
Ask what the reader compares. If nothing, write prose. Also check for horizontal rules dropped between every section, and emoji used as structural markers, which are the same instinct in a different costume.
